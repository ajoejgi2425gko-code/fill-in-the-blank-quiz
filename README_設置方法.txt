穴埋め暗記クイズ PWA（GitHub Pages・Google Keep共有対応）

■ GitHub Pagesへの設置
1. ZIPを展開します。
2. 中の index.html / manifest.json / sw.js / icon-192.png / icon-512.png を、GitHub Pagesで公開しているリポジトリの公開ルートにアップロードします。
3. GitHub Pagesの反映を待ち、サイトを開きます。
4. AndroidのChromeでサイトを開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

■ Google Keepから共有
1. AndroidのChromeでPWAを一度開いておきます。
2. Google Keepで共有したいメモを開き、共有メニューから「穴埋め暗記クイズ」または「穴埋めクイズ」を選びます（表示名は端末により異なります）。
3. 共有した文章が入力欄に入ります。必要に応じて文章を編集し、アプリ内の問題生成操作を行ってください。

■ 注意
・GitHub Pagesのプロジェクトサイト（例: https://ユーザー名.github.io/リポジトリ名/）に対応する相対パス設定です。
・Google Keep共有は対応ブラウザ／端末で動作します。実機での最終確認は、短いメモを共有して行ってください。
・元の穴埋め暗記クイズの主要機能・画面構成は維持しています。


【追加機能】
・共有メニューからの文章受け取り機能は維持しています。
・TXT/MD/CSV/HTMLファイルの取り込みに対応しました。
・文字情報を含むPDFは、初回にネット接続してPDF解析ライブラリを読み込むことで取り込めます。
・Web記事URLの自動取得機能は削除しました。失敗しやすい機能を表示せず、共有機能やファイル取り込みをご利用ください。
・PNG/JPG/WebPなどの画像と、文字情報のないスキャンPDFはOCRで読み取れます。OCRは初回にインターネット接続が必要です。日本語・英語の認識結果は誤りが含まれる場合があるため、取り込み後に確認してください。
・EPUBの直接解析は未対応です。
